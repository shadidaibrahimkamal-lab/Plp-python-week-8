# Personal Mini-Toolkit

This project is a simple menu-driven toolkit made with Python. It includes a number guessing game, a to-do list, a simple calculator, and a name formatter. The program runs in a loop so the user can try different tools without restarting the app.

## How to run
1. Open a terminal in the project folder.
2. Run the following command:
   python toolkit.py
3. Choose a tool from the menu and follow the prompts.

## Reflection
This project helped me bring together several Python ideas in one program. The hardest part was planning the menu loop so each tool could run smoothly and return to the menu afterward. The bug that took the longest to fix was making sure invalid menu choices did not crash the program. I learned that clear input validation and friendly messages make a program much easier to use. If I had one more week, I would add a countdown timer and a password generator to make the toolkit more useful. I also want to improve the code by making each tool more detailed and easier to expand later. Overall, this project showed me how useful small Python programs can be when they are organized well.
